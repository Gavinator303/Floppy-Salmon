# Floppy Salmon Game

A small browser game built in a single HTML file.

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
cd /Users/gavinlangley-valey/floppy-salmon-game
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Controls

- Space or Up Arrow: jump
- Z: shoot invasive carp
- Click or tap: start / jump

## Notes

This project is intentionally lightweight and uses plain HTML, CSS, and JavaScript.
